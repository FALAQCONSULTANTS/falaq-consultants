# فلق للاستشارات الهندسية | Falaq Engineering Consultants

الموقع الرسمي لمكتب **فلق للاستشارات الهندسية** - القصيم، المملكة العربية السعودية.

## نبذة عن المكتب
مكتب هندسي معتمد يقدم حلولاً هندسية متكاملة ومبتكرة في مجالات:
- التصميم المعماري والداخلي
- الاستشارات الهندسية والتخطيط العمراني
- الإشراف الهندسي وإدارة المشاريع
- حساب الكميات والمطابقة لكود البناء السعودي
- إصدار التراخيص والتقارير الفنية المعتمدة عبر منصة بلدي

## التقنيات المستخدمة
- **React 19**
- **TypeScript**
- **Tailwind CSS**
- **Lucide Icons**
- **Vite**

---

## التشغيل محلياً (Local Development)

1. تثبيت الحزم:
```bash
npm install
```

2. تشغيل بيئة التطوير:
```bash
npm run dev
```

3. بناء المشروع للإنتاج:
```bash
npm run build
```
